Interdisciplinary Projects and Research

Here are a few major projects that showcase my ability to solve problems and build complete systems.

Transcodex — Media Management Platform

Overview: Built during an industrial training at iTechBrains (May–June 2026): a full-stack MERN platform for uploading, optimizing, and delivering images and videos via API, with authentication and access control.

Methodologies: JWT-based auth with role-based access control (user/admin); a pluggable storage-adapter pattern (local filesystem, cloud-ready) via a factory pattern; an image pipeline with Sharp (thumbnails, multi-resolution WebP) and a video pipeline with FFmpeg for adaptive-bitrate HLS (360p–1080p); a React (Vite, Tailwind CSS) frontend with drag-and-drop upload, a media gallery, and an hls.js player.

Outcomes: A working REST API for media CRUD and auth, backed by MongoDB/Mongoose schemas for users and media metadata.

Automatic Identification & Segmentation of Code-Mixed Text

Overview: An NLP system to detect and segment code-mixed (English–Hindi–Gujarati) text at the word level in romanized/Latin-script documents.

Methodologies: Designed a synthetic data generation pipeline — transliterated a Gujarati monolingual corpus into Latin script, then applied controlled code-mixing to build a labeled training corpus without manual annotation. Trained a transformer-based language identification model to tag each word's source language.

Outcomes: Segmented mixed-language text into contiguous, language-specific spans, evaluated across all three languages, enabling downstream use in translation and sentiment analysis on multilingual, romanized text.

Custom Unix-like Shell

Overview: A POSIX-inspired command shell written in C, supporting piping, I/O redirection, and foreground/background job control.

Methodologies: Used fork, execvp, and waitpid for process/job control; handled signals (SIGINT, SIGTSTP) for suspension and interruption; implemented built-ins (cd, exit, jobs, history) and a custom tokenizer/parser with environment variable expansion.

Critical Analysis: The main challenges were safe buffer handling and memory management while parsing arbitrary command-line input.

8-bit Computer Project

Overview: Built a functional 8-bit computer from scratch on breadboards, guided by Ben Eater's instructional series.

Methodologies: Designed and assembled key components, including the clock, registers, ALU, control logic, and memory using discrete components.

Outcomes: Implemented a basic instruction set and programmed simple operations, developing a deep, practical understanding of computer architecture, binary computation, and bus systems.

Critical Analysis: The main challenge was debugging timing and bus-level hardware issues, which provided a comprehensive grasp of low-level electronics.
