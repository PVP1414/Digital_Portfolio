Interdisciplinary Projects and Research

Here are a few major projects that showcase my ability to solve problems and build complete systems.

8-bit Computer Project

Overview: Built a functional 8-bit computer from scratch on breadboards, guided by Ben Eater's instructional series.

Methodologies: Designed and assembled key components, including the clock, registers, ALU, control logic, and memory using discrete components.

Outcomes: Implemented basic machine instructions and developed a deep, practical understanding of computer architecture, binary computation, and bus systems.

Critical Analysis: The main challenge was debugging hardware issues and optimizing circuit timing, which provided a comprehensive grasp of low-level electronics.

Simon Game Project

Overview: Developed an interactive web-based version of the "Simon" memory game.

Methodologies: Used HTML, CSS, JavaScript, and jQuery to manage game state, generate dynamic sequences, and validate user input.

Outcomes: A fully responsive game with sound effects, visual feedback, and a progressing level system based on user accuracy.

Critical Analysis: The core challenge was managing the game's state machine (e.g., player's turn vs. computer's turn) and synchronizing animations/sounds with the game logic.

Dice Game Project

Overview: Developed an interactive two-player dice game using HTML, CSS, and JavaScript.

Methodologies: Implemented game logic for random dice roll generation and dynamic image updates based on the roll.

Outcomes: A responsive and visually appealing interface that displays real-time results and declares a winner based on the game outcomes.
